\section{Conclusion}
\label{sec:conclusion}

% W: What proposed
This paper presented NutriAgent, a grounded conversational agent for eating-out
decisions that addresses the unreliable numbers of LLM-based dietary advice.
% X: eXcel
Its key idea is to let deterministic clinical and allergen rules filter the
candidates before any LLM call, so that the LLM only ranks and explains a safe
pool and every number in a reply is checked against the database. The design
also damps unreliable wearable energy data and keeps working offline.
% Y: Yields
An offline functional check of the prototype on 5 profiles and 45 evaluations
confirmed that the gate and ranking behave as designed, with a calorie MAE of
114.48\,kcal and sub-millisecond latency; these figures verify the
implementation rather than the approach.
% Z: Zen
Future work will implement the numeric check of Gemini replies, Gemini-based
intent parsing, and shuffled schema-constrained scoring; build the full
datasets; run the baseline comparison and the user study; and replace the
conservative CKD rule with graded rules once serum potassium data are
available.
