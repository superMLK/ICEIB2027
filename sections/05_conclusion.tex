\section{Conclusion}
\label{sec:conclusion}

% W: What proposed
This paper presented NutriAgent, a grounded conversational agent for eating-out
decisions that addresses the unreliable numbers of LLM-based dietary advice.
% X: eXcel
Deterministic clinical and allergen rules filter the candidates before any LLM
call, so the LLM only ranks and explains a safe pool, every reply number is
checked against the database, and the agent keeps working offline.
% Y: Yields
An offline check on 45 evaluations confirmed that the gate and ranking behave
as designed; it verifies the implementation, not the approach.
% Z: Zen
Future work will implement the remaining LLM components in
Table~\ref{tab:prototype}, build the datasets, run the baseline comparison and
user study, and grade the CKD rule once serum potassium data are available.
